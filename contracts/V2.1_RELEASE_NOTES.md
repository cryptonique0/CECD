## 🚀 Usage Quick Start

### 1. Apply Decay to Inactive User

```javascript
// Check status first
const status = await contract.getTrustScoreDecayStatus(userAddress);
console.log('Pending Decay:', status.pendingDecay);

// Apply decay
await contract.applyTrustScoreDecay(userAddress);
```

### 2. Penalize Bad Actor

```javascript
// Emergency Desk only
await contract.reduceTrustScore(
    maliciousUser,
    20,
    "Multiple false incident reports"
);
```

### 3. Reward Good Behavior

```javascript
// Emergency Desk only
await contract.increaseTrustScore(
    goodVolunteer,
    10,
    "Outstanding emergency response"
);
```

### 4. Configure Decay Settings

```javascript
// Owner only
await contract.updateTrustScoreDecayConfig(
    2,       // 2 points per period
    172800,  // 2 days per period
    true     // Enable
);
```

### 5. Monitor All Users

```javascript
const users = await contract.allUsers;
for (const user of users) {
    const status = await contract.getTrustScoreDecayStatus(user);
    if (status.pendingDecay > 5) {
        console.log(`${user} needs decay: ${status.pendingDecay} points`);
    }
}
```
